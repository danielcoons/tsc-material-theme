## 🛠️ Toolkit Description
The TSC Material Tookit implements the theory and application of color schemes to LabVIEW front panels. Installing the **VIP** file will add **FOUR** menu items to the LabVIEW Tools bar:

[Tools->TSC->Material Theme Editor...](https://danielcoons.com/material-theme/theme-editor/)  
[Tools->TSC->Edit a Button--Material...](https://danielcoons.com/material-theme/button-editor/)  
[Tools->TSC->Edit VI Theme...](https://danielcoons.com/material-theme/edit-vi-theme/)  
> Can also be invoked by Quick Drop Shortcut! `Ctrl+C` by default  

[Tools->TSC->View VI's Color Palette...](https://danielcoons.com/material-theme/color-palette/)

## 📜 Prerequisites

LabVIEW 2021 (32-bit), LabVIEW 2021 (64-bit), or any newer version.  

## 📥 Installation

The recommended way to install the Material Theme Toolkit is via [VI Package Manager (VIPM)](https://www.vipm.io/package/tsc_lib_tsc_material_theme/). This installs the latest stable release.

## 📌 Reference Sites:
This code is based on Google's Material 3 User Interface Coloring/Design Guidelines: <https://m3.material.io>  
Material Icons Toolkit: <https://github.com/danielcoons/material-icons-toolkit> easy access to various sizes of the material icon library images
