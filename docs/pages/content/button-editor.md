# Button Editor UI

Launch the **Button Editor UI** (`Tools → TSC → Edit a Button--Material...`) to create new buttons that follow the theme rules.  

Choose a theme file (`.json`), then choose the theme type, color level, button family and button type to see a preview of every change.  

Colors for the six Boolean actions (`False`, `True`, `Click when False`, `Click when True`, `Hover when False`, `Hover when True`) load from the Material rules and can be edited. Change other aspects of the **Boolean** as desired and save when ready.  

> Hover and click actions are all visible in the preview pane.

When a multiple-image type is chosen, there are paths to load in all **four** button images (`False`, `True`, `Click when False`, `Click when True`).  

![Button Editor UI](/assets/material-theme/images/Button-Editor--UI--main.png)

The **Glyphs** tab lets you define an image library, so you can drag and drop glyphs onto buttons. See the [Material Icons Toolkit](https://github.com/danielcoons/material-icons-toolkit) for an archive of PNG images of the Google Material library.
