# TSC Material Theme

This toolkit gives the ability to have a Dynamic UI theme in LabVIEW User Interfaces.

Install the VIP package from [VIPM](https://www.vipm.io/package/tsc_lib_tsc_material_theme/).

## Toolkit description

The TSC Material Toolkit implements the theory and application of color schemes to LabVIEW front panels. Installing the VIP adds **four** menu items to the LabVIEW Tools menu:

- [Tools → TSC → Material Theme Editor...](/material-theme/theme-editor/)
- [Tools → TSC → Edit a Button--Material...](/material-theme/button-editor/)
- [Tools → TSC → Edit VI Theme...](/material-theme/edit-vi-theme/) (also available through Quick Drop, `Ctrl+C` by default)
- [Tools → TSC → View VI's Color Palette...](/material-theme/color-palette/)

## Reference sites

This code is based on Google's Material 3 user interface coloring and design guidelines: [m3.material.io](https://m3.material.io).

- [Material Icons Toolkit](https://github.com/danielcoons/material-icons-toolkit): easy access to various sizes of the Material icon library images.
- [Material Theme Builder](https://material-foundation.github.io/material-theme-builder/): create the theme JSON. 

✨ As of version `v3.2.1` there is no longer a need to do a conversion step to another file type. This toolkit can use the JSON directly!
