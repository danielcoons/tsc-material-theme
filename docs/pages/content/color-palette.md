# Color Palette UI

The color palette UI gives access to all color rules and levels in the theme file and theme mode saved with a VI, or selected in the Material Theme Editor. To show this dialog, go to `Tools → TSC → View VI's Color Palette...`.  

With this window you can:  

- Export the selected colors (`up to 18`) to the LabVIEW **User Colors**.
  - You can also set these in the LabVIEW Options dialog:  
   `Environment → Custom Colors.`
  - When saving through the VI, restart LabVIEW to apply the update.
- Copy and paste colors (when stopping the VI using the `Stop VI` button).
- See the hex codes for all colors in the theme.
- Restore the LabVIEW defaults if you no longer want the theme colors applied.

![Color Palette UI](/assets/material-theme/images/Color-Palette--color%20palette.png)

Exported colors are available in the color picker tools of the Tools palette.
